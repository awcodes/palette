# Palette

A color picker for Filament forms and infolists that limits choices to a preset palette of colors instead of a free-form picker.

## Compatibility

| Filament version | Package version |
|------------------|-----------------|
| 3.x              | 1.x             |
| 4.x              | 2.x             |
| 4.x & 5.x        | 3.x             |

## Installation

```bash
composer require awcodes/palette
```

The components need your Tailwind theme to see the package's views. See [Installation](https://docs.aw.codes/palette/3.x/installation) for that step.
